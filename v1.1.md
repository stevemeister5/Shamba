The Shamba Smart v1.1 "East Africa Pest-Guard" Master Prompt
Role: Senior Android Architect, AI/ML Engineer, and Agronomist.

Context: Upgrade the Shamba Smart application (Kotlin/Jetpack Compose) for the 16-acre farm in Korogwe. The system must now provide high-precision, offline identification of agricultural pests endemic to East Africa.

Objective: Implement a production-grade Vision Pipeline and a synchronized data-recording architecture for crop health.

PHASE 1: Architectural Hardening (Infrastructure)
Hardware-Backed Security: Refactor KeystoreManager.kt to use a random AES-256 key generated in the Android Keystore. Ensure SQLCipher uses this key. Implement encrypted Daily SD Card Backups.

Revision-Based Delta Sync: Add revision_id and last_modified_by to all 28 tables. Update SyncWorker to use a Watermark strategy (only sync rows where last_updated > local_max_timestamp) to handle Tanga’s unreliable connectivity.

Read-Model Optimization: Implement Room @DatabaseView for the Dashboard and Plot Analytics to maintain 144Hz fluidity.

PHASE 2: East African Pest Intelligence (ONNX)
Regional Pest Classifier: Deploy a quantized YOLOv8-medium or EfficientNet-B0 model via ONNX Runtime, specifically trained or fine-tuned on the following East African pests:

Maize: Fall Armyworm (FAW), Maize Stalk Borer, and Maize Streak Virus symptoms.

Legumes/Beans: Bean Fly, Aphids, and Blight patterns.

General: Desert Locusts and Tomato Leafminer (Tuta absoluta).

Multi-Stage Inference:

Stage 1: Detect the pest/symptom via bounding box.

Stage 2: Classify the Severity Level (Low, Moderate, Critical) based on the percentage of leaf area affected or pest density.

Offline Knowledge Mapping: Link detections to the "Maarifa" engine. If FAW is detected, automatically surface the specific Tanzania Ministry of Agriculture approved management protocol.

PHASE 3: Automated Data Recording & Scouting
Vision-to-Database Mapping: Create a new ScoutingReport entity. On a "Confirmed Detection," the app must automatically populate:

plot_id: (Derived from GPS/Farm Map coordinates).

pest_type: (From the ONNX model output).

severity_score: (1-5 scale).

gps_coordinates: (-5.15°S, 38.48°E precision).

image_uri: (Pointer to a compressed, encrypted local image).

Scouting Heatmaps: Update the OSMDroid Farm Map to display a "Pest Heatmap." Use color-coded markers (Green to Red) based on the ScoutingReport data to help the owner visualize the spread across the 16 acres.

Actionable Alerts: If a "Critical" severity is logged, generate a dashboard notification for the "Admin" (Owner) to authorize chemical application or biological control.

PHASE 4: Multi-Species Livestock Vision (NPU Optimized)
Species Pre-Processor: MobileNetV3 classifier to route frames to Cattle, Goat, Sheep, or Chicken models.

BCS Scoring: Anatomical landmark regression for Cattle (Tailhead/Ribs), Goats (Lumbar), Sheep (Loin), and Chickens (Keel Bone prominence).
