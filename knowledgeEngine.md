🧠 Maarifa — Offline Agricultural Knowledge Engine
Shamba Smart · Korogwe, Tanga · English Only · Text Interface · No AI Model Runtime

CONCEPT
Build an embedded, fully offline agricultural knowledge engine called Maarifa inside the Shamba Smart tablet application. Maarifa is not a separate screen the farmer navigates to — it is a knowledge layer woven into every module of the application that surfaces relevant guidance exactly when and where it is needed, plus a dedicated Ask Maarifa panel accessible from any screen via a persistent floating tab on the right edge of the display.
Core principles:

Fully offline. No internet required for any feature at any time
Text only. No voice input, no speech recognition, no text-to-speech
English only throughout all UI, all knowledge content, all responses
No on-device AI language model. No quantised LLM. No llama.cpp. No model inference runtime. All intelligence comes from structured data, full-text search, pre-computed vector similarity, and a hand-authored deterministic rule engine
The only model bundled is all-MiniLM-L6-v2 in ONNX format (~23MB) used exclusively for generating text embeddings at document ingestion time and query time. This model converts text to vectors only — it generates no language output and cannot hallucinate
Every answer is assembled from retrieved knowledge base chunks passed through a rule engine — not generated by a language model

RETRIEVAL PIPELINE
Every text query submitted by the user passes through this exact pipeline in sequence:
1. INTENT CLASSIFICATION
   Rule-based keyword and pattern matching assigns one intent:
   symptom_query | dosage_lookup | planting_advice |
   breeding_query | weather_risk | cheese_process |
   nutrition_query | general_lookup

2. ENTITY EXTRACTION
   Extract from query text:
   - Species (goat, sheep)
   - Crop name
   - Drug name
   - Animal ID or name (matched against live herd)
   - Plot name (matched against live plot registry)
   - Symptom keywords
   - Date or time references

3. CONTEXT INJECTION
   Read live farm SQLite database and inject:
   - If animal named → profile, health history, weight trend,
     milk records, current treatment and withdrawal status
   - If plot named → crop type, planting date, last inputs
     applied, current growth stage, plot size in acres
   - Always inject → today's date, current month,
     current season (long rains / short rains / dry),
     last 7 days of manually logged rainfall

4. KNOWLEDGE RETRIEVAL
   Run in parallel:
   a) MiniSearch full-text search on the relevant domain index
      scoped by intent and entity (crops index for planting
      queries, livestock index for animal queries, etc.)
   b) Vectorise the query using all-MiniLM-L6-v2 via ONNX
      Runtime, compute cosine similarity against all stored
      chunk vectors in SQLite, return top 10 by score
   Merge both result sets, deduplicate, rank by combined
   relevance score. Ingested documents searched alongside
   bundled knowledge base — results from ingested documents
   labelled with their source title.

5. RULE ENGINE OVERLAY
   Apply deterministic rules to the retrieved chunks:
   - diagnostic_rules → ranked differential diagnoses
     with confidence: High / Medium / Low
   - agronomy_rules → season-adjusted planting and
     input timing recommendations
   - nutrition_rules → weight-based ration calculations
   - breeding_rules → cycle and kidding date projections
   - withdrawal_tracker → calculate safe milk and meat
     dates from treatment records
   - alert_rules → flag outbreak risk if 3+ animals
     show similar symptoms within 7 days

6. RESPONSE ASSEMBLY
   Assemble structured answer from retrieved chunks
   and rule engine outputs using fixed templates
   per intent type. Structure:

   ┌─ Summary (2–3 plain sentences)
   ├─ Detailed guidance (structured sections, not walls of text)
   ├─ Farm-specific note (injected from live data if relevant)
   ├─ Recommended action (what to do now, what to monitor)
   ├─ Warning flags (vet referral triggers, notifiable disease
   │  alerts, withdrawal period blocks, outbreak escalations)
   ├─ Sources (bundled knowledge base entry name +
   │  any ingested document titles that contributed)
   └─ Related topics (3 tappable linked knowledge cards)

APPLICATION MODULE INTEGRATION
Maarifa integrates into every module of the application. It is never just a standalone screen. The following defines exactly how knowledge surfaces in each module.
DASHBOARD

Morning Briefing Card generated on every app open. Maarifa reads today's date, current season, all animal health flags, crop growth stages, feed stock levels, recent weather log entries. Outputs a plain-English paragraph of what needs attention today
Every alert on the dashboard links directly through to the relevant Maarifa knowledge card rather than just showing a date reminder
Seasonal tip strip: 3 rotating knowledge cards relevant to the current month in Korogwe drawn from agronomic and livestock calendars

LIVESTOCK MODULE

Each animal's profile page has a persistent right-panel Maarifa context card that reads that animal's breed, age, lactation stage, weight trend, and last health event — and outputs contextual guidance specific to that animal's current situation
When a symptom or condition is entered in a health record, the symptom checker fires automatically in a side panel pre-populated with the animal's species and the entered symptom — the worker does not navigate away
When a vaccine is logged, Maarifa auto-fills recommended dose, route, and next due date from the formulary based on species and vaccine selected
When a drug treatment is logged, Maarifa automatically calculates the milk withdrawal end date and meat withdrawal end date and posts a blocking flag on that animal's milk collection log until the withdrawal period clears
If weight trend is declining over 3 or more consecutive entries, Maarifa surfaces nutritional deficiency and health differential cards relevant to the breed and age
When a mating is recorded, Maarifa calculates expected kidding or lambing date, posts it to the calendar, and automatically creates a pre-kidding preparation task 7 days before the expected date
When heat signs are logged, Maarifa shows optimal mating window timing guidance
If daily milk yield drops more than 20% from the 7-day average for any doe, Maarifa surfaces a milk drop card listing the most probable causes ranked by likelihood given that animal's records
When a death is recorded, Maarifa prompts for suspected cause and returns biosecurity and herd prevention guidance relevant to that cause
If 3 or more animals show similar symptoms within any 7-day window, Maarifa escalates automatically with a potential outbreak flag and herd-level response protocol

CROPS MODULE

Each plot's detail page shows a live Maarifa crop status card: current growth stage based on days since planting, what inputs are due this week, what to scout for given current season and logged humidity
When a pesticide or herbicide is selected in the input log, Maarifa displays PHI, mixing rate per 20L knapsack, protective equipment required, and re-entry interval before the record is saved
When a harvest is logged, Maarifa shows post-harvest handling guidance for that crop: drying targets, storage conditions, aflatoxin risk indicators where applicable
When a new planting record is started, Maarifa pre-fills recommended spacing, seed rate per acre, expected days to harvest, and a full fertiliser schedule based on the plot size
When a silage pit is opened, Maarifa shows the quality assessment checklist. When daily draw-down is logged, it recalculates days of stock remaining and flags if below the 21-day threshold

CHEESE MODULE

When a new batch is created, Maarifa presents the complete process guide for the selected cheese type covering all temperatures, timing, culture rates, rennet dosing, and expected pH at each stage
When a defect is logged in batch quality notes, Maarifa immediately returns the defect diagnosis card: most likely cause and which process step to adjust in the next batch
If logged milk pH or acidity is outside the acceptable range, Maarifa surfaces a milk quality card: causes, whether the batch is safe to proceed, corrective actions
When a batch is marked as packaged, Maarifa shows the TFDA labelling requirements checklist
Maarifa tracks milk-to-cheese conversion efficiency across all batches and surfaces a benchmark comparison showing the gap between actual yield and target yield for the cheese type, with the financial impact of that gap

FEED MODULE

When any feed item drops below its reorder threshold, Maarifa surfaces a feed gap risk card showing days of stock remaining at current draw rate and the nutritional impact on the herd if not restocked
The ration calculator is powered by Maarifa's livestock nutrition knowledge: recommended dry matter intake, energy and protein requirements by animal class (lactating, dry, pregnant, growing kid/lamb), adjusted by breed and body weight entered
When silage quality observations are entered, Maarifa scores the silage and recommends whether it is safe to feed, at what inclusion rate, and whether to blend with other feeds

FINANCE MODULE

When a veterinary drug purchase is logged as an expense, Maarifa cross-references the drug name and flags if the price paid is significantly above the expected TZS range in the formulary
Enterprise P&L summaries include a Maarifa benchmark strip: reference figures for what a well-managed dairy goat enterprise of this herd size should yield per month, so actuals can be compared against knowledge-base benchmarks

LABOUR MODULE

When a task is created (e.g. deworm sheep flock), the task detail page shows the relevant Maarifa knowledge card: recommended protocol, products to use, safety precautions, records to capture afterward
If a worker logs a free-text observation containing symptom-related keywords, Maarifa parses the text and suggests linking it to a health event and opening the symptom checker

CALENDAR MODULE

Maarifa writes directly to the calendar: all vaccination due dates, deworming rotation reminders, expected kidding and lambing dates, crop harvest windows, cheese aging milestones, silage feed-out start dates, seasonal planting windows for Korogwe
Tapping any Maarifa-generated calendar event opens the relevant knowledge card for that event type


THE ASK MAARIFA PANEL
A persistent floating tab on the right edge of the tablet display is visible on every screen at all times. Tapping it slides out a side panel without navigating away from the current screen. The panel has three tabs:
Ask tab:
Large text input field at the bottom of the panel. The farmer types any question in plain English. The retrieval pipeline processes it and returns a structured answer rendered as cards with collapsible sections — not walls of text. Drug dosage answers render in a distinct highlighted table format. Conversation history is saved locally so the farmer can scroll back through all previous questions and answers. Each answer shows its sources.
Browse tab:
Full hierarchical encyclopaedia tree: Crops → individual crop entries. Livestock → Goats → health / reproduction / nutrition / breeds. Livestock → Sheep → same structure. Medicines → searchable formulary. Cheese → process guides and defect reference. Weather and Seasons → Korogwe climate calendar. Any entry can be bookmarked. The search bar is always visible at the top of the browse tab for direct keyword search across all bundled knowledge.
Saved tab:
All bookmarked knowledge entries and any entries the farmer has starred for quick reference. Organised by domain. Accessible instantly without searching.

        → Goat / Sheep

KNOWLEDGE INBOX — FEEDING NEW DOCUMENTS INTO MAARIFA
The farmer and administrator can expand Maarifa's knowledge base at any time by importing new documents directly from the tablet. This is a first-class feature accessible from Settings → Knowledge Management.
Supported input formats:

PDF (text-based only — no scanned image PDFs, no OCR)
Plain text files (.txt)
Word documents (.docx)
Pasted text via a text input field for content copied from another app

Ingestion pipeline:
1. DOCUMENT SELECTION
   User selects file from tablet storage or USB,
   or pastes text directly into the input field.
   User assigns a title and selects a domain tag:
   Crops / Livestock / Medicines / Cheese /
   Weather / General

2. TEXT EXTRACTION
   PDF → pdfjs extracts text layer
   DOCX → mammoth.js extracts text
   Image-based PDFs flagged as unsupported
   with clear error message

3. CHUNKING
   Extracted text split into chunks of 400 words
   with 50-word overlap between consecutive chunks.
   Each chunk stores metadata:
   document title, domain tag, section header
   if detectable, page number, date ingested

4. KEYWORD INDEXING
   Each chunk added to the MiniSearch index
   with its metadata. Immediately searchable
   via full-text search on completion.

5. VECTOR EMBEDDING
   Each chunk passed through all-MiniLM-L6-v2
   via ONNX Runtime (CPU only, no GPU required).
   Generates a 384-dimension vector per chunk.
   Vectors stored in SQLite alongside chunk text.
   Processing runs in a background thread with
   a visible progress indicator. A 100-page PDF
   produces approximately 200–250 chunks and
   takes 2 to 4 minutes on mid-range tablet hardware.

6. AVAILABLE IN MAARIFA
   All chunks from the document are now searchable
   alongside the bundled knowledge base. Answers
   that draw from ingested documents clearly display
   the document title and ingestion date as the source,
   visually distinguished from core bundled knowledge.
Knowledge Inbox management screen shows:

Library list: all ingested documents with title, domain tag, date added, chunk count, file size
Processing status bar during ingestion
Delete document option: removes the document, all its chunks, and all its vectors from the index
Source visibility: every Maarifa answer that draws from an ingested document shows the document title as a citation

What ingests well:
FAO crop and livestock manuals, TARI and TALIRI extension bulletins, TVLA disease reference guides, university research papers on East African agriculture, ILRI small ruminant production manuals, Korogwe district agricultural extension reports, journal articles on goat cheese production, veterinary drug data sheets, any text-based farming book or field guide.
What will not ingest:
Scanned image PDFs with no text layer, handwritten notes, Excel spreadsheets or tabular data files, video or audio content.

SAFETY GUARDRAILS — NON-NEGOTIABLE
Every drug dosage answer must append the line: "Always confirm dosage and treatment with a licensed veterinarian before administering."
Symptom checker outputs must always show confidence level (High / Medium / Low) and never present a differential as a definitive diagnosis.
Any answer where PPR, FMD, Anthrax, Brucellosis, or CCPP appears as a differential must display: "This is a notifiable disease in Tanzania. Contact the Tanzania Veterinary Laboratory Agency (TVLA) or your district veterinary officer immediately."
The withdrawal period tracker must default to the more conservative (longer) estimate when treatment date data is ambiguous.
Planting date advice must note: "Based on 30-year historical averages for Korogwe District. Verify current season conditions with your local agricultural extension officer."
Maarifa never fabricates drug names, doses, crop inputs, or diagnostic conclusions outside its bundled and ingested knowledge base. If a query cannot be answered from available knowledge, it returns: "This topic is not covered in the current knowledge base. Consider importing a relevant document via the Knowledge Inbox."
All knowledge entries carry a source attribution tag and last-verified date. Ingested documents are labelled with their title and the date they were added.
